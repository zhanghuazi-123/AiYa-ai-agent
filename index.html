功能介绍
🤖
AiYa 是一个 AI 对话助手，支持文字和语音交互。 你可以像和朋友聊天一样跟它说话，它会用语音回答你。（AiYa拥有长期记忆，主动学习，自我迭代的能力。经过长期交流，会更懂你。）
快速开始
1
配置大模型 → 切换到 LLM 标签，选 Provider、填 API Key，点 Activate & Save
2
配置语音（可选） → 切换到 Voice 标签，选 ASR/TTS Provider，填对应凭证
3
开始对话 → 在输入框打字按回车，或点击麦克风按钮开始语音输入
LLM 设置说明
Provider大模型供应商
Model模型名称（如 deepseek-v4-flash）
API KeyAPI 密钥，保存后自动隐藏
Base URL可选。兼容 OpenAI API 的请求地址
Temperature创意程度。0=严谨，1=平衡，2=放飞
💡 点 Activate & Save 后若显示 ✅ 已激活即可使用。
语音设置说明

ASR（语音识别） — 把你的语音转成文字

Doubao火山引擎豆包 ASR。需填 App ID / Access Token / Resource ID
Aliyun阿里云语音识别（需 API Key）
WhisperOpenAI Whisper API（需 API Key）

TTS（语音合成） — 让 AiYa 用语音回答你

Doubao火山引擎豆包 TTS。需 TTS Key
MiniMaxMiniMax TTS（可选填 Key，留空则用 LLM Key）
OpenAIOpenAI TTS。需 OpenAI Key 和 Base URL
💡 Voice 下拉可选不同音色。设置完后点 Save Voice Settings。
语音对话技巧
  • 点击麦克风按钮开始录音，再次点击停止
  • 说完话后 AiYa 会自动检测停顿并发送
  • AiYa 回答完后会恢复录音，形成自然的对话流
  • 可以随时点击麦克风按钮手动停止录音
  • 如果觉得回声大，检查音箱音量或使用耳机
上下文设置
Weather in Context对话中注入本地天气信息
Trending Topics注入微博/知乎热搜，让 AiYa 知道时事
City你的所在城市，用于天气和本地信息
Heartbeat心跳间隔（分钟）。AiYa 会主动询问或推送提醒

Tools 标签页列出当前可用的工具（函数调用）， 供大模型调用以执行搜索、查询天气等操作。无需手动配置。
